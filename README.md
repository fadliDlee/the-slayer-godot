# ⚔️ The Slayer - 2D Action Platformer

A 2D Action Platformer game built with **Godot Engine 4**. This project implements a **Finite State Machine (FSM)** architecture for intelligent enemy AI and smooth player mechanics.

## 🛠️ Tech Stack & Features
- **Engine:** Godot Engine 4 (GDScript)
- **Architecture:** Finite State Machine (FSM) for character and enemy behaviors.
- **Evaluation Method:** System Usability Scale (SUS) & Cognitive Walkthrough.
- **Features:** Dynamic combat system, intelligent boss/enemy AI, and custom dialogue triggers.
